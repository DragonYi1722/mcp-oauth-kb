# MCP 工具契约

| 项目 | 内容 |
|---|---|
| 协议 | MCP 2026-07-28 |
| 传输 | Streamable HTTP（`POST /mcp`） |
| 认证 | OAuth 2.1 Bearer Token |
| 版本 | v1.0 |

---

## 1. 通用约定

### 1.1 请求头

| 头 | 必需 | 说明 |
|---|---|---|
| `Authorization` | 是 | `Bearer <access_token>` |
| `Content-Type` | 是 | `application/json` |
| `MCP-Protocol-Version` | 是 | `2026-07-28` |
| `Mcp-Method` | 是 | 如 `tools/call`、`tools/list` |
| `Mcp-Name` | 工具调用时 | 工具名，如 `search_documents` |
| `X-Request-Id` | 否 | 客户端可传入，用于链路追踪；缺省由服务端生成 |

### 1.2 身份

- 用户身份只来自 token 的 `sub`；
- 工具入参不允许出现 `user_id`、`owner_id`、`tenant_id`；
- 若出现，服务端忽略并记录 `identity_field_ignored` 告警。

### 1.3 错误格式

工具返回结构化错误：

```json
{
  "error": {
    "code": "FORBIDDEN_SCOPE",
    "message": "missing scope: kb.write",
    "request_id": "req_01J..."
  }
}
```

不返回堆栈、SQL、内部路径。

### 1.4 分页

- `limit` 默认 20，最大 50；
- `cursor` 为服务端签发的不可猜测字符串（MVP 可用 base64url + HMAC）；
- 响应中的 `next_cursor` 为空表示结束。

## 2. 工具清单

| 工具 | scope | 角色要求 | 只读 |
|---|---|---|---|
| `whoami` | 任意登录 | 无 | 是 |
| `search_documents` | `kb.read` | 无 | 是 |
| `get_document` | `kb.read` | 无 | 是 |
| `create_document` | `kb.write` | 无 | 否 |
| `update_document` | `kb.write` | owner / manager / admin | 否 |
| `archive_document` | `kb.admin` | admin | 否 |

## 3. `whoami`

返回当前身份与权限，用于验证登录链路。

**输入**：无。

**输出**：

```json
{
  "sub": "b1f0c6a2-...",
  "username": "alice",
  "email": "alice@example.com",
  "department": "engineering",
  "roles": ["employee"],
  "scopes": ["kb.read", "kb.write"],
  "issuer": "http://localhost:8080/realms/kb",
  "expires_at": 1760000000
}
```

**错误**：`UNAUTHENTICATED`。

## 4. `search_documents`

按关键词检索当前用户可见的文档。

**输入 Schema**：

```json
{
  "type": "object",
  "required": ["query"],
  "properties": {
    "query": { "type": "string", "minLength": 1, "maxLength": 512 },
    "limit": { "type": "integer", "minimum": 1, "maximum": 50, "default": 20 },
    "cursor": { "type": "string", "maxLength": 256 }
  },
  "additionalProperties": false
}
```

**输出**：

```json
{
  "items": [
    {
      "id": "4f3c...",
      "title": "2026 Q2 复盘",
      "snippet": "……本季度重点……",
      "owner": "alice",
      "department": "engineering",
      "visibility": "department",
      "updated_at": "2026-11-01T10:00:00Z"
    }
  ],
  "next_cursor": "eyJvZmZzZXQiOjIwfQ..."
}
```

**规则**：

- 只返回满足可见性条件的 `active` 文档；
- 不返回正文全文，只返回 ≤ 200 字摘要；
- `query` 做参数化 `ILIKE`/`pg_trgm` 查询；
- 空结果返回 `items: []`，不报错。

**错误**：`UNAUTHENTICATED`、`FORBIDDEN_SCOPE`、`VALIDATION_ERROR`。

---

## 5. `get_document`

读取单篇文档。

**输入**：

```json
{
  "type": "object",
  "required": ["document_id"],
  "properties": {
    "document_id": { "type": "string", "format": "uuid" }
  },
  "additionalProperties": false
}
```

**输出**：

```json
{
  "document": {
    "id": "4f3c...",
    "title": "2026 Q2 复盘",
    "content": "……",
    "owner": "alice",
    "department": "engineering",
    "visibility": "department",
    "status": "active",
    "created_at": "2026-06-30T09:00:00Z",
    "updated_at": "2026-11-01T10:00:00Z",
    "version": 3
  }
}
```

**规则**：

- 无权访问或不存在 → 统一 `NOT_FOUND`；
- 不返回 owner 的 `sub` 以外的敏感信息。

---

## 6. `create_document`

创建文档，`owner_id` 强制取 token `sub`。

**输入**：

```json
{
  "type": "object",
  "required": ["title", "content", "visibility"],
  "properties": {
    "title": { "type": "string", "minLength": 1, "maxLength": 200 },
    "content": { "type": "string", "minLength": 1, "maxLength": 100000 },
    "visibility": { "enum": ["private", "department", "org"] }
  },
  "additionalProperties": false
}
```

**输出**：

```json
{
  "document_id": "4f3c...",
  "created_at": "2026-11-14T12:00:00Z"
}
```

**规则**：

- `visibility=department` 需要用户有 `department` claim；否则降级为 `private`；
- 不接收 `owner_id`、`department_id`；
- 写审计日志，`args_digest` 包含标题与正文摘要，不存正文。

---

## 7. `update_document`

更新标题、正文或可见性。

**输入**：

```json
{
  "type": "object",
  "required": ["document_id", "version"],
  "properties": {
    "document_id": { "type": "string", "format": "uuid" },
    "version": { "type": "integer", "minimum": 1 },
    "title": { "type": "string", "maxLength": 200 },
    "content": { "type": "string", "maxLength": 100000 },
    "visibility": { "enum": ["private", "department", "org"] }
  },
  "additionalProperties": false
}
```

**输出**：更新后的文档摘要（同 `get_document`，`content` 可省略）。

**规则**：

- 乐观锁：`version` 必须等于当前版本，否则 `CONFLICT`；
- 只有 owner、同部门 manager、admin 或 ACL `write` 可更新；
- 每次更新 `version + 1`、`updated_at = now()`。

---

## 8. `archive_document`

软删除文档。

**输入**：

```json
{
  "type": "object",
  "required": ["document_id", "reason"],
  "properties": {
    "document_id": { "type": "string", "format": "uuid" },
    "reason": { "type": "string", "minLength": 3, "maxLength": 200 }
  },
  "additionalProperties": false
}
```

**输出**：

```json
{
  "archived": true,
  "archived_at": "2026-11-14T12:30:00Z"
}
```

**规则**：

- 需要 `kb.admin` scope **且** `admin` 角色；
- 幂等：已归档再调用返回成功；
- 可在进阶版提供 `restore_document`。

## 9. 错误码汇总

| 码 | HTTP | 触发条件 | 客户端建议 |
|---|---|---|---|
| `UNAUTHENTICATED` | 401 | 无 token / 验签失败 / 过期 | 重新走 OAuth |
| `FORBIDDEN_SCOPE` | 403 | 缺少 scope | 申请更多 scope |
| `NOT_FOUND` | 404 | 不存在或无权 | 不重试 |
| `VALIDATION_ERROR` | 400 | 参数不合法 | 修正参数 |
| `CONFLICT` | 409 | 版本冲突 | 重新读取后重试 |
| `RATE_LIMITED` | 429 | 超过限流 | 退避重试 |
| `UPSTREAM_UNAVAILABLE` | 503 | JWKS/DB 不可用 | 指数退避 |
| `INTERNAL` | 500 | 未预期 | 携带 request_id 反馈 |

## 10. 工具实现模板

```python
from mcp.server.auth.middleware.auth_context import get_access_token
from pydantic import BaseModel, Field

class SearchInput(BaseModel):
    query: str = Field(min_length=1, max_length=512)
    limit: int = Field(default=20, ge=1, le=50)
    cursor: str | None = Field(default=None, max_length=256)

@mcp.tool()
async def search_documents(params: SearchInput) -> dict:
    token = get_access_token()
    require_scope(token, "kb.read")
    actor = await ensure_user(token)           # upsert users，返回部门/角色
    items, next_cursor = await repo.search(
        actor=actor, query=params.query,
        limit=params.limit, cursor=params.cursor,
    )
    return {"items": items, "next_cursor": next_cursor}
```

约束：

- 每个工具第一行取 token 并校验 scope；
- 输入用 Pydantic 模型，`additionalProperties: false` 等价的严格模式；
- 仓储层只接受 `Actor` 对象，不接受原始 token；
- 异常统一映射为错误码。
